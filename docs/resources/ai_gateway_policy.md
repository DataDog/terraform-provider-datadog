# datadog_ai_gateway_policy (Resource)

Provides a Datadog AI Gateway routing policy resource. A policy routes requests that match an inbound pattern to ordered tiers of provider and model targets: the gateway tries the first tier, then falls back to the next. Each inbound pattern has one policy per scope, organization-wide or for one user. This resource is in Preview.

## Example Usage

```terraform
# Route coding-agent traffic to Codex on the production provider, falling back to any provider serving Claude Sonnet.
resource "datadog_ai_gateway_policy" "coding_agent" {
  inbound = "coding-agent"

  tiers = [
    {
      targets = [{ provider = "prod-us", model = "gpt-5.2-codex" }]
    },
    {
      targets = [{ model = "claude-sonnet-5*" }]
    },
  ]
}
```

## Schema

### Required

- `inbound` (String) Inbound request pattern the policy applies to, such as `coding-agent` or `gpt-5*`. It must not contain whitespace, and `*` is allowed only as a trailing wildcard. Changing it replaces the policy.
- `tiers` (Attributes List) Ordered fallback tiers. The gateway routes to a target in the first tier and falls back to later tiers. (see [below for nested schema](#nestedatt--tiers))

### Optional

- `priority` (Number) Routing priority of the policy. Defaults to `0`.
- `user_id` (String) UUID of a Datadog user. When set, the policy applies only to that user's requests; otherwise it applies to the whole organization. Changing it replaces the policy.

### Read-Only

- `id` (String) The ID of this resource.
