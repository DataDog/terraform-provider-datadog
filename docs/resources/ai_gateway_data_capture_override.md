# datadog_ai_gateway_data_capture_override (Resource)

Provides a Datadog AI Gateway data capture override resource. An override sets the data capture mode for the requests that match its scope, instead of the organization default set by `datadog_ai_gateway_governance`. When several overrides match a request, `metadata_only` wins over `full_capture`. This resource is in Preview.

## Example Usage

```terraform
# Record only metadata for the coding assistant's requests, whatever the organization default is.
resource "datadog_ai_gateway_data_capture_override" "coding_assistant" {
  name             = "coding-assistant-metadata-only"
  mode             = "metadata_only"
  metadata_capture = ["tool_usage", "tool_names"]
  tags = {
    ml_app = "coding-assistant"
  }
}
```

## Schema

### Required

- `mode` (String) Data capture mode for matching requests. `metadata_only` records request metadata without prompt or completion content; `full_capture` also records content. Valid values are `metadata_only`, `full_capture`.
- `name` (String) Display name of the override. Names need not be unique. String length must be at least 1.

### Optional

- `confirm_full_capture` (Boolean) Set to `true` to confirm a change that can turn on full capture for more requests, such as creating a `full_capture` override or deleting a `metadata_only` one. The API rejects such a change without it. Defaults to `false`.
- `metadata_capture` (Set of String) Items that Metadata-only capture adds to matching spans. Some items require others: `tool_output_size`, `tool_names`, and `conversation_shape` require `tool_usage`, and `input_size_by_role` requires `tool_output_size`. When unset, Terraform leaves the current items unchanged. Set an empty set to record no items.
- `tags` (Map of String) Request tags the override matches, such as `provider`, `model`, or `ml_app`. A request matches when it has all of these tags. Keys must be lowercase.
- `team_id` (String) UUID of a Datadog Team. When set, the override matches requests that select this team with the `x-ai-gateway-team` header. At least one of `team_id`, `user_id`, and `tags` is required.
- `user_id` (String) UUID of a Datadog user. When set, the override matches requests from this user.

### Read-Only

- `id` (String) UUID of the override.
- `revision` (Number) Revision of the override. It increases with every change.
